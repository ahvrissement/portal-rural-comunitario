# Portal Rural Comunitário 🌱

**Conectando o Campo ao Futuro Digital**

Um portal comunitário completo para zonas rurais que oferece acesso digital a educação, serviços públicos e conectividade, funcionando mesmo com internet limitada através de tecnologia offline.

## 🌟 Características Principais

### 🎨 Design Rural Autêntico
- Paleta de cores que evoca a vida no campo (verdes naturais, tons terrosos, dourados)
- Layout responsivo otimizado para desktop e mobile
- Animações fluidas e transições suaves
- Imagens personalizadas geradas especificamente para o tema rural brasileiro

### 📱 Progressive Web App (PWA)
- **Funcionalidade Offline**: Acesso a conteúdos mesmo sem internet
- **Instalação Nativa**: Pode ser instalado como app no celular/desktop
- **Service Worker**: Cache inteligente para sincronização automática
- **Indicadores de Status**: Mostra conexão online/offline em tempo real

### 🌾 Páginas e Funcionalidades

#### 🏠 Página Inicial
- Hero impactante com call-to-actions
- Visão geral dos recursos disponíveis
- Estatísticas da comunidade
- Links diretos para principais seções

#### 📚 Educação Rural
- Cursos especializados em agricultura familiar
- Conteúdo sobre sustentabilidade e tecnologias rurais
- Artigos e pesquisas atualizadas
- Sistema de progresso e certificações

#### 🏛️ Serviços Públicos
- Acesso facilitado a documentos governamentais

#### 👥 Comunidade

- Eventos e workshops locais
- Sistema de sugestões personalizadas

#### 📞 Contato
- Informações de suporte
- Canais de comunicação
- Formulário de contato (em desenvolvimento)

## 🚀 Tecnologias Utilizadas

### Frontend
- **React 19**: Framework JavaScript moderno
- **Vite**: Build tool rápido e eficiente
- **TailwindCSS**: Framework CSS utilitário
- **Shadcn/UI**: Componentes UI modernos e acessíveis
- **React Router**: Navegação entre páginas
- **Lucide Icons**: Ícones modernos e consistentes

### PWA & Offline
- **Service Worker**: Cache e funcionalidade offline
- **Web App Manifest**: Configuração para instalação nativa
- **Cache API**: Armazenamento local de recursos

### Deploy
- **Manus Platform**: Deploy automático e otimizado
- **URL Permanente**: https://gvyatpxn.manus.space
